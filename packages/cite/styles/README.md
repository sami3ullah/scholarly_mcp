# Citation styles

`american-medical-association.csl` is the "AMA Manual of Style 11th edition" style from the
[CSL style repository](https://github.com/citation-style-language/styles), updated
2026-02-06, licensed under
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). It is copied unchanged.

APA and Vancouver ship with `@citation-js/plugin-csl`; BibTeX and RIS are not CSL styles and
come from `@citation-js/plugin-bibtex` and `@citation-js/plugin-ris`.
